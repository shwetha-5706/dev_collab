# DevCollab Dashboard

AI-powered mission control dashboard for developer teams.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:4174](http://localhost:4174) and sign in with `shwetha@devcollab.io`.

## Features

### Authentication
- Login, signup, forgot password, OTP verification
- Google/GitHub social login (mock), remember me, session persistence
- Animated coding background, floating particles, AI welcome message
- Workspace creation flow after signup

### Workspace & Projects
- Create/switch workspaces, invite members, role permissions (Owner/Admin/Member/Viewer)
- Full project CRUD with health meters, AI completion predictions, risk indicators

### Kanban & Tasks
- Drag-and-drop board (To Do → In Progress → In Review → Done)
- Task detail panel with comments, activity log, AI summaries, live viewers
- Burnout detection, AI subtask generation, deadline risk warnings

### Developer Tools
- **Snippets** — search, filter by language, favorites, trending, copy code
- **Wiki** — collaborative docs, knowledge graph, AI summaries, version history
- **AI Assistant** — standup reports, blocker detection, sprint health, focus mode
- **Code Reviewer** — quality/security/performance analysis with AI scores

### Collaboration
- Real-time activity feed with contribution graph
- Team presence indicators, member management, invites
- Notification center with AI priority ranking and filters
- Analytics dashboard with burnout prediction and team comparison

### UI/UX
- Glassmorphism design, dark/light mode, Framer Motion animations
- Responsive layout with mobile bottom nav, command palette (⌘K), quick actions FAB

## Stack

React 18 · TypeScript · Vite · Framer Motion · Heroicons
